# Kimmy Karlovich — Rural & Ranch Real Estate

Static SEO site for Kimmy Karlovich, rural property specialist in Roseburg / Douglas County, Oregon.

- `gen/` — Node static-site generator (`node gen/build.mjs` rebuilds everything)
- `gen/data/` — all content: locations, services, guides, blogs
- `docs/` — built site (287 pages), served by GitHub Pages

To change the domain later: edit `SITE` in `gen/lib/site.mjs`, rebuild, add CNAME.
